# TesloShop

Este proyecto esta generado en version 19.1.8. de angular

DESPLIEGUE

1. descargar las dependencias con el comando `npm install`
2. Crear los environments en el proyecto con el comando `ng g environments`
3. Ingresar la informacion de las variables de entorno `export const environment = {
  baseUrl: 'http://localhost:3000/api',
};`
